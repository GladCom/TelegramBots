Класс для поиска семантического сходства фразы и массива других фраз.
Для определения сходства используется метод класса InterestsComparer Compare. В результате вернется массив float от 0 до 1.
По очереди для каждой переданной фразы.
Интерпретация:
1.0 – идеальное совпадение (например, два одинаковых предложения).
0.7–0.9 – очень близкие темы (синонимы, смежные понятия).
0.4–0.6 – умеренная схожесть (общая тематика, но разный контекст).
0.1–0.3 – слабая связь (разные темы).
0.0 – полное отсутствие связи.
Для работы требуется интерпретатор Python с установленными библиотеками "numpy", "sentence_transformers" и "sklearn".
Предпочтительная версия-3.9.
Путь до dll нужно указать в python_config.json.
Сами библиотеки можно установить через pip в командной строке или терминале (как правило, располагается в папке Scipts):
pip install numpy
pip install sentence_transformers
pip install sklearn
